The version of "@mantine/*" used here is not the one you know — it's a new, updated version. When using the library, ALWAYS look into the node_modules source code or fetch the LLM-readable documentation from: https://mantine.dev/llms.txt

This project uses Tauri version 2! Always fetch documentation from: https://v2.tauri.app/ or https://docs.rs/tauri/~2/
